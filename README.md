

# Cook Inlet Planning Area, Migratory Bird Explorer

## Overview

This web application allows users to explore the habitat use of birds in the Lower Cook Inlet across the annual cycle, and improves our understanding of disturbance risks associated with potential energy infrastructure and associated vessels. It may also inform oil spill risk assessments and response. The specific objectives of this web application for the Cook Inlet Planning Area, Alaska, include:

* Developing a comprehensive geospatial database for storing, managing, and analyzing avian spatial data and associated data resources.

* Describing spatial and temporal patterns of bird use across the annual cycle including breeding, migratory, and wintering periods.

* Facilitating access to priority information including abundance, distribution, key sites, and migratory movements.

* Identifying and describing potential risks to birds and conservation measures to avoid, minimize, and mitigate impacts from energy infrastructure development in the Cook Inlet Planning Area, Alaska.

## Usage

**Data management.R** includes workflows for generating the data objects in the **Processed data objects** folder.

The **www** folder contains various **README.Rmd** files. 

**app.R** includes the source code for a web application that allows users to explore the habitat use of birds in the Lower Cook Inlet, Alaska.
